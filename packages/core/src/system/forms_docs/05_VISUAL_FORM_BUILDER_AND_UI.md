# 🎨 05. Визуальный конструктор и интерфейс админки

Документация по работе с визуальным конструктором форм в панели администратора (`apps/admin/src/features/forms`).

---

## 1. Архитектура экрана управления

1. **Реестр форм (`FormsListView`):**
   - Карточки форм с бейджами типа (`booking`, `contact`, `test`, `custom`), статусом активности и таргетом.
   - Золотая звезда и бейдж `Predefinito` для активного шаблона по умолчанию.
   - Быстрые действия: назначить по умолчанию, дублировать, просмотреть предпросмотр, удалить.

2. **Визуальный конструктор (`VisualFormBuilder`):**
   - Левая колонка: метаданные формы, статус, тип и таргетинг (категория курсов или точный курс).
   - Правая колонка: список полей с возможностью перемещения вверх/вниз стрелками, редактирования и удаления.

3. **Интерактивное Live Preview (`FormPreviewModal`):**
   - Переключение между Desktop и Mobile (390px) симуляцией.
   - Отображение защищенного блока покупателя (Core Fields) и кастомных полей.

---

## 2. Добавление и настройка полей

При нажатии «Aggiungi Campo» открывается модальное окно с настройками:
* **Label:** Отображаемое название поля для клиента (например, *«Livello di partenza»*).
* **Key:** Уникальный системный ключ латиницей (если оставить пустым, генерируется автоматически из label).
* **Тип поля:** `text`, `select`, `textarea`, `checkbox`, `number`, `date`.
* **Target:** `student` (данные ученика), `purchaser` (данные родителя/заказчика), `booking` (заявка).
* **Тумблеры:** `Campo Obbligatorio` (обязательное) и `Campo Attivo` (включено).
* **Опции (для `select`):** список вариантов `Название:значение` построчно.
