# Модуль Успеваемости (`grades`)

Этот модуль предоставляет электронный журнал оценок, позволяя преподавателям просматривать и анализировать результаты тестов студентов по языковым аспектам (говорение, аудирование, чтение, письмо).

---

## Архитектура и Структура файлов

```
grades/
├── components/
│   └── valutazioni-view.tsx  # Таблица оценок по курсам
├── index.ts                  # Точка экспорта Public API фичи
└── types.ts                  # Структура данных успеваемости
```

---

## 1. Типы данных (`types.ts`)

* **`Grade`** ([types.ts](file:///Users/krimson/PROJECTS/class-bloom-81/src/features/grades/types.ts))
  Содержит показатели баллов по шкале 0-100 для четырех основных языковых навыков:
  * `studentId`: Идентификатор ученика.
  * `corsoId`: Идентификатор курса.
  * `speaking`: Навык разговорной речи.
  * `listening`: Навык восприятия речи на слух.
  * `reading`: Навык чтения.
  * `writing`: Навык письменной речи.

---

## 2. Основные компоненты

* **`ValutazioniView`** ([valutazioni-view.tsx](file:///Users/krimson/PROJECTS/class-bloom-81/src/features/grades/components/valutazioni-view.tsx))
  Отображает матрицу успеваемости в виде таблицы для выбранного курса:
  * Позволяет выбрать курс из выпадающего списка.
  * Рассчитывает средний балл (`media`) на лету для каждого ученика на основе четырех навыков.
  * Раскрашивает бейджи среднего балла в зависимости от успешности:
    * `85+`: Зеленый (Отлично)
    * `70-84`: Синий (Хорошо)
    * `55-69`: Желтый (Удовлетворительно)
    * `<55`: Красный (Неудовлетворительно)
