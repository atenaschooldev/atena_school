# Модуль Панели Аналитики (`dashboard`)

Этот модуль собирает и визуализирует ключевые показатели работы школы, выводя графики и помогая администратору следить за активностью.

---

## Архитектура и Структура файлов

```
dashboard/
├── components/
│   └── dashboard-view.tsx    # Панель аналитики (виджеты, KPI, Recharts)
└── index.ts                  # Точка экспорта Public API фичи
```

---

## 1. Функционал и Компоненты

* **`DashboardView`** ([dashboard-view.tsx](file:///Users/krimson/PROJECTS/class-bloom-81/src/features/dashboard/components/dashboard-view.tsx))
  Интегрирует в себя следующие информационные слои:
  * **Виджеты KPI**:
    * Общее количество активных студентов (извлекается из стейта `app-store`).
    * Общее количество курсов в школе.
    * Количество занятий, запланированных на сегодня.
    * Средний процент посещаемости по школе.
  * **Интерактивный график "Presenze settimanali"**: Построен на базе библиотеки `recharts` с использованием градиентной заливки зоны (`AreaChart`), визуализируя среднюю посещаемость по дням недели.
  * **Список "Prossime lezioni"**: Выводит карточки уроков, которые проходят в текущий день недели, помогая быстро сориентироваться в расписании и кабинетах.
