# Архитектура Фронтенда — Atena SIS (School Information System)

Данный проект представляет собой современное одностраничное веб-приложение (SPA) для академического управления школой, разработанное с использованием **React 19**, **TypeScript**, **Zustand** и **Tailwind CSS v4**.

---

## 🛠 Технологический стек

* **Базовый фреймворк**: [React 19](https://react.dev)
* **Роутинг**: [TanStack Router & Start](https://tanstack.com/router) — обеспечивает типобезопасный (type-safe) роутинг, вложенные макеты (nested layouts) и серверную загрузку данных.
* **Управление состоянием**: [Zustand](https://zustand.docs.pmnd.rs) — ультралегкий стейт-менеджер. Данные автоматически кэшируются и синхронизируются с локальным хранилищем браузера (`localStorage`) через middleware `persist`.
* **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com) с интеграцией кастомных дизайн-токенов из JSON-структуры [tokens.json](file:///Users/krimson/PROJECTS/class-bloom-81/src/theme/tokens.json).
* **Сборщик**: [Vite 8](https://vite.dev) для мгновенной сборки и горячей замены модулей (HMR).

## 🏛 Структура проекта (Feature-First)

Мы следуем модульному принципу группировки по фичам (**Feature-First Layout**). Вместо разделения файлов по техническим ролям (`components/`, `types/`, `actions/` глобально), файлы группируются вокруг бизнес-доменов в директории `src/features/`. Это позволяет полностью изолировать логику конкретного модуля.

```
src/
├── components/          # Глобальные UI-компоненты общего назначения (кнопки, таблицы, сайдбар)
├── features/            # Вертикальные слайсы бизнес-фич (изолированные домены)
│   ├── students/        # Фича: Студенты
│   ├── teachers/        # Фича: Преподаватели
│   ├── courses/         # Фича: Курсы
│   ├── schedule/        # Фича: Расписание
│   ├── documents/       # Фича: Документы и подписи
│   ├── grades/          # Фича: Успеваемость
│   ├── attendance/      # Фича: Посещаемость
│   ├── payments/        # Фича: Оплаты
│   ├── activity-log/    # Фича: Лог действий
│   └── dashboard/       # Фича: Панель аналитики
├── hooks/               # Общие React-хуки (например, useMobile)
├── lib/                 # Системные библиотеки, утилиты и централизованные моки
├── routes/              # Тонкие обертки маршрутизации TanStack Router
├── stores/              # Глобальные хранилища состояния (Zustand)
├── theme/               # Сгенерированные TS-токены и конфигурации темы
├── router.tsx           # Инициализация роутера TanStack
└── styles.css           # Глобальные стили Tailwind v4 с CSS-переменными
```

## 📦 Внутренняя структура фичи (Module Specification)

Каждая папка внутри `src/features/<name>` должна быть изолированной и следовать строгому контракту импортов:
1. **`types.ts`**: Описывает интерфейсы доменных моделей (например, `Student`, `Teacher`).
2. **`components/`**: Содержит внутренние UI-компоненты (формы, диалоги выбора, специфичные карточки), используемые только в рамках этой фичи.
3. **`index.ts`**: Публичная точка входа фичи (Public API). Экспортирует только те типы и компоненты, которые разрешено импортировать внешним модулям (например, `StudentiView`). Импорт файлов в обход `index.ts` (deep imports) запрещен.

## 💾 Управление состоянием (Zustand & LocalStorage)

Глобальное состояние приложения управляется через стейт [app-store.ts](file:///Users/krimson/PROJECTS/class-bloom-81/src/stores/app-store.ts):
* Хранит списки студентов, преподавателей, курсов и документов.
* Инициализируется из предопределенных данных [mock-data.ts](file:///Users/krimson/PROJECTS/class-bloom-81/src/lib/mock-data.ts) при первом запуске.
* Состояние сохраняется локально в браузере под ключом `atena-scuola`, что позволяет сохранять внесённые изменения между перезагрузками страниц.
* Имеет встроенные мутации: `addStudent`, `updateStudent`, `addTeacher`, `addDocument`, `addCourse` и т.д.

## 🎨 Дизайн-система и токенизация

Цветовые палитры и стили компонентов привязаны к конфигурационному файлу темы [tokens.json](file:///Users/krimson/PROJECTS/class-bloom-81/src/theme/tokens.json). 
* CSS-переменные генерируются в `:root` блока файла [styles.css](file:///Users/krimson/PROJECTS/class-bloom-81/src/styles.css).
* При рендеринге интерфейса используются семантические стили Tailwind (`bg-card`, `text-primary`, `border-border/40`), гарантирующие идеальную совместимость со светлой и тёмной темами.
