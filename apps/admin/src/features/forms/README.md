# 🎨 Admin Forms Engine UI (`apps/admin`)

Клиентский модуль управления динамическими формами, шаблонами анкет и таргетингом полей в панели администратора Atena School CRM (`/moduli`).

---

## 🏛️ Архитектура компонентов

```
features/forms/
├── components/
│   ├── forms-list-view.tsx       # Реестр шаблонов форм с фильтрами и быстрыми действиями
│   ├── visual-form-builder.tsx   # Визуальный конструктор полей и настройка таргетинга
│   └── form-preview-modal.tsx    # Интерактивное Live Preview (Desktop & Mobile)
├── hooks/
│   └── use-forms.ts              # React Query хук для работы с REST API /admin/forms
└── types.ts                      # Реэкспорт типов из @atena/api-types
```

---

## 🧩 Ключевые возможности интерфейса

### 1. Реестр форм (`FormsListView`)
* **Фильтрация по типам:** Таблетки-фильтры (`Tutti`, `Booking`, `Contact`, `Test`, `Custom`).
* **Индикация таргетинга:** Бейджи области действия формы (Все курсы / Конкретная категория / Точный курс).
* **Быстрые действия:**
  * ⭐ *Imposta come predefinito* — назначение дефолтной формы в 1 клик.
  * 📋 *Duplica* — создание копии шаблона для быстрой доработки.
  * 👁️ *Anteprima* — запуск интерактивного модального окна предпросмотра.
  * ✏️ *Modifica* — переход в визуальный конструктор.

### 2. Визуальный конструктор (`VisualFormBuilder`)
* **Настройка метаданных:** Название, служебное описание, тип формы, тумблеры активности и дефолтного статуса.
* **Настройка таргетинга (Scope):** Привязка к слагу категории курсов или конкретному UUID курса.
* **Менеджер полей:**
  * Добавление полей разных типов (`text`, `select`, `checkbox`, `textarea`, `number`, `date`).
  * Назначение таргета (`purchaser` — покупатель, `student` — студент/ребёнок, `booking` — заявка).
  * Быстрое переключение обязательности (`is_required`) и активности (`is_enabled`).
  * Сортировка порядка полей стрелками вверх/вниз.

### 3. Интерактивное Live Preview (`FormPreviewModal`)
* Переключатель вида: **Desktop** (двухколоночный вид) vs **Mobile** (симуляция экрана смартфона шириной 390px).
* Отображение защищённых полей покупателя (Имя, Фамилия, Email, Тел, Codice Fiscale) и динамических полей в реальном времени.
