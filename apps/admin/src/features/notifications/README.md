# 🎨 Admin Notifications UI (`apps/admin`)

Клиентский модуль управления шаблонами, триггерами и мониторингом отправок в панели администратора Atena School CRM.

---

## 🏛️ Архитектура компонентов

```
features/notifications/
├── components/
│   ├── notifications-view.tsx         # Корневой контейнер со вкладками (Шаблоны, Триггеры, Логи)
│   ├── notification-triggers-view.tsx # Обзор системных правил и условий
│   ├── notification-logs-view.tsx     # Журнал отправок и инспектор сообщений
│   ├── trigger-editor-drawer.tsx      # Боковая шторка инспекции триггера
│   ├── template-editor-drawer.tsx     # Боковая шторка редактирования шаблона
│   ├── test-send-modal.tsx            # Модальное окно тестовой отправки
│   ├── create-template-dialog.tsx     # Диалог создания нового шаблона
│   └── builder/
│       └── visual-template-builder.tsx# No-Code конструктор блоков с Live Preview
├── hooks/
│   ├── use-notification-templates.ts  # React Query хук для шаблонов и логов
│   └── use-notification-triggers.ts   # React Query хук для триггеров и событий
└── __tests__/                         # Покрытие компонентов тестами
```

## 🧩 Ключевые возможности интерфейса

### 1. Вкладки экрана управления (`NotificationsView`)
* **Шаблоны (Templates):** Карточки сводных метрик (Всего, Email, Telegram, Активные), фильтры по каналам и статусу, создание, редактирование и удаление шаблонов.
* **Триггеры (Triggers):** Просмотр правил автоматизации, связанных событий, условий и получателей.
* **Журнал отправок (Logs):** История доставки с фильтрацией и поиском.

### 2. Визуальный конструктор блоков (`VisualTemplateBuilder`)
* **Двухканальный режим:** переключение между Email (HTML с табличной версткой) и Telegram (форматирование HTML-тегов).
* **Палитра блоков:** добавление заголовков, персонализированных приветствий, сводных таблиц бронирования, платежных реквизитов IBAN, кнопок призыва к действию (CTA), примечаний и подвалов.
* **Интерактивное Live Preview:** мгновенный рендеринг итогового сообщения с подстановкой тестовых переменных при изменении любого поля.
* **Вставка переменных:** кликабельная панель тегов `{{purchaser_name}}`, `{{course_name}}`, `{{total_amount}}` и т.д.

### 3. Тестовая отправка (`TestSendModal`)
* Позволяет отправить рабочий образец письма на произвольный email или сообщение в Telegram-чат перед сохранением изменений в шаблоне.
* Автоматически валидирует формат адресата и выводит подробную ошибку провайдера в случае сбоя.

### 4. Журнал аудита (`NotificationLogsView`)
* Просмотр статусов `SENT` (зеленый бейдж) и `FAILED` (красный бейдж).
* Просмотр детального JSON запроса (переданные переменные) и ответа (ID письма в Resend или `message_id` в Telegram).
* Отображение таймлайна статусов вебхуков доставки Resend (`email.delivered`, `email.opened`, `email.clicked`).
