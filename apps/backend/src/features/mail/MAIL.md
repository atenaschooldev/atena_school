# Модуль Почтовых Рассылок (`mail`)

Этот модуль отвечает за отправку электронных писем (email-уведомлений) пользователям, студентам и преподавателям CRM.

---

## Архитектура и Структура файлов

```
mail/
├── mail.controller.ts                # Маршруты управления почтой
├── mail.service.ts                   # Интеграция с SMTP / транспорт отправки
└── mail.module.ts                    # Зависимости модуля
```

---

## 1. Сервисный слой (`mail.service.ts`)

* **`MailService`** ([mail.service.ts](file:///Users/krimson/PROJECTS/nest_backend/src/features/mail/mail.service.ts))
  * Действует как абстракция над транспортным клиентом `nodemailer`.
  * При инициализации модуля (`onModuleInit`) считывает параметры подключения к SMTP-серверу из переменных окружения.
  * **Режим разработки (Mock Mode)**: Если параметры SMTP не настроены в `.env`, служба автоматически переходит в режим тестирования и выводит все отправляемые письма в консоль логирования вместо реальной отправки.

---

## 2. Контроллер (`mail.controller.ts`)

Определяет эндпоинты API:

* **`POST /mail/send`**:
  Отправить произвольное письмо получателю.
  Принимает параметры:
  * `to` (строка, email получателя)
  * `subject` (строка, тема письма)
  * `text` (строка, текстовая версия)
  * `html` (опционально строка, HTML-разметка письма)

Эндпоинт защищен `AuthGuard`, доступен только администраторам (`@Roles('admin')`) и логируется через перехватчик аудита (`@Audit('mail', 'send')`).

---

## Переменные окружения для конфигурации SMTP (.env)

Для активации реальной отправки писем настройте следующие переменные:

```env
SMTP_HOST="smtp.example.com"
SMTP_PORT=587
SMTP_USER="your-username"
SMTP_PASSWORD="your-password"
SMTP_FROM="Atena School <noreply@atenaschool.it>"
```
Если данные переменные отсутствуют, служба работает в режиме имитации (Mock Mode), отображая письма в системном логе.
