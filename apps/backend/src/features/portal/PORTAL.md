# Модуль Портала Учеников и Родителей (`portal`)

Этот модуль отвечает за Личный Кабинет платформы (Next.js App `apps/app`) и Мобильного приложения (React Native). Он предоставляет защищенный доступ к курсам, расписаниям уроков и профилю авторизованного пользователя.

---

## Архитектура и Структура файлов

```
portal/
├── portal.controller.ts  # Защищенные эндпоинты (AuthGuard)
├── portal.service.ts     # Бизнес-логика дашборда и синхронизации
├── portal.module.ts      # Модуль NestJS
└── PORTAL.md             # Документация модуля
```

---

## 1. Контроллер Портала (`portal.controller.ts`)

*Все эндпоинты защищены `@UseGuards(AuthGuard)` и требуют заголовок `Authorization: Bearer <supabase_jwt>`.*

* **`GET /api/v1/portal/dashboard`**
  * **Описание**: Возвращает обогащенный дашборд пользователя.
  * **Бизнес-логика**: Автоматически ищет и связывает гостевые покупки по email пользователя (`sync_user_profile_from_bookings`), фильтрует заказы по родительскому/ученическому профилю и возвращает профиль.
  * **Ответ**: `{ success: true, user: UserProfile, bookings: EnrichedBooking[] }`.

* **`GET /api/v1/portal/bookings/:id/lessons`**
  * **Описание**: Возвращает расписание всех уроков курса для конкретного бронирования.

* **`PATCH /api/v1/portal/profile`**
  * **Описание**: Обновляет ФИО и номер телефона пользователя.
  * **Входные данные**: `UpdateProfileDto` (`profileName`, `profilePhone`).

---

## 2. Сервисный Слой (`portal.service.ts`)

* **`PortalService`**
  * Проверяет и верифицирует контекст текущего пользователя (`req.user.id`).
  * Выполняет автоматическую привязку гостевых чекаутов по совпадению `email`.
  * Гарантирует изоляцию данных: пользователь может просматривать **только свои собственности и зачисления**.
